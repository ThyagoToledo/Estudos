## Como Executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/ThyagoToledo/estudos.git
   ```

2. Acesse a pasta do projeto:
   ```bash
   cd estudos
   ```

3. Execute o menu interativo:
   ```bash
   python Codes/main.py
   ```
